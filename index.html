Volvo Home Dashboard

Terms and Conditions

Last updated: October 25, 2026

1. Purpose

Volvo Home Dashboard is a private, non-commercial application developed exclusively for personal use. It displays information about an authorized Volvo vehicle on a private home dashboard.

2. Vehicle Data

The application uses official Volvo Cars APIs to retrieve vehicle information, including:

  • Battery charge level and electric range
  • Charging status
  • Vehicle location
  • Fuel level and odometer, where available

3. Authorization

Vehicle information is accessed only after authorization through the vehicle owner's Volvo ID.

4. Data Processing and Privacy

Vehicle data is processed and stored on a privately operated server. The dashboard is intended for private household use.

Vehicle data is not sold or intentionally made publicly available. This public website contains only legal information and does not display vehicle data.

5. Availability

Vehicle information may be delayed, inaccurate, or temporarily unavailable. The application is provided without any guarantee of availability.

6. Disclaimer

This application is an independent private project. It is not affiliated with, endorsed by, or officially supported by Volvo Cars.

7. Changes

These terms may be updated if the application or its intended use changes.
